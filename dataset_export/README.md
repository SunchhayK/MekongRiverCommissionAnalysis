# MekongPulse static dataset export

Generated by `export.py` from the project's verified snapshots (`data/commune_gazetteer_2025.json`, `data/stations.json`, `data/raw/mef_commune_boundaries.geojson`). Re-run it from `projects/` with `python3 dataset_export/export.py` after any gazetteer update.

## Files

- `communes.csv` — 1,661 rows, one per Cambodian commune (2025 gazetteer).
- `stations.csv` — 4 MRC hydrolological stations on the Mekong and Tonle Sap.
- `communes.geojson` — 1,544 commune polygons with all gazetteer attributes joined onto properties. 117 communes (mostly newly split 2024/2025 communes in Ratanakiri/Mondul Kiri) have no polygon in the MLMUPC source and are excluded.
- `timeseries/` — live recorded history from the deployment database (below).
- `historical/mrc_daily_all.csv` — **172,829 daily water levels, 22 MRC stations basin-wide, 1992-2026** (merged from wet/dry; wet/dry seasons don't overlap). `historical/mrc_daily_wet.csv` and `mrc_daily_dry.csv` keep the split forms. Regenerate with `python3 dataset_export/scrape_mrc_history.py`.

## historical/

Daily mean water level in meters above local gauge zero, per station, from the MRC RFMMC hydrograph backend (`ffw.mrcmekong.org/fetchwet_new.php` / `fetchdry_new.php`, scraped 2026-10-25). One row per station-date.

| Column | Meaning |
| --- | --- |
| `date` | Calendar date (dry-season rows normalized from season to calendar year) |
| `station` | RFMMC short code (KOM = Kompong Cham, NEA = Neak Luong, ...); full registry in `stations_historical.csv` |
| `station_name`, `telemetry_id` | Display name; live-network telemetry ID where one exists (blank for Phnom Penh Port / Bassac) |
| `year` | Calendar year of the row |
| `water_level_m` | Daily level; the site renders 0.00 as chart-null, preserved as blank |
| `floodStage`, `alarmStage` | Station thresholds (m above gauge zero), repeated per row |

Coverage notes: continuous wet+dry for 21 of 22 stations from 2007; 2006 dry only for some; reference wet years 1992/1998/2000 selected by RFMMC; the wet 2014 column was zeroed at source so that season is dry-only. The dry payload contains impossible dates (e.g. `2026-02-29`) because rows are indexed by day-of-season; those rows are dropped.

`stations_historical.csv` maps each RFMMC code to coordinates, river, country, and the live-network telemetry ID (from `api.mrcmekong.org/api/v1/time-series/telemetry/recent/stations`, 79 stations). Phnom Penh Port and Phnom Penh (Bassac) are not on the live network; their coordinates are manual. File order is upstream → downstream (CSA in Yunnan → CDO in the Mekong Delta).

Typical analyses this supports: flood-frequency/extreme-value analysis per station (GEV/POT), trend tests on annual maxima (Mann-Kendall), seasonality (STL decomposition), upstream→downstream flood-wave lag correlation (Chiang Saen → Kompong Cham → Tan Chau), and year clustering / regime classification.

## timeseries/

Recorded by the 15-minute sentinel-patrol cron (telemetry sync → risk → alerts) into the staging server's PostgreSQL, exported 2026-10-25 via read-only queries. All timestamps UTC.

| File | Rows | Content |
| --- | --- | --- |
| `timeseries/hydro_observations.csv` | 2,628 | Per-station water level (m above local gauge zero), rate of rise, rainfall, temp — 4 stations × 15-min syncs, 2026-10-17 → 2026-10-25 |
| `timeseries/weather_forecasts.csv` | 7,065 | Per-province forecast snapshots: 48h/7d precipitation, 24h max rain, soil moisture — 25 provinces, hourly refresh |
| `timeseries/sentinel_patrol_runs.csv` | 675 | One row per patrol: stations polled, communes evaluated, alerts dispatched, duration |
| `timeseries/sentinel_alerts.csv` | 23 | All DANGER-tier alerts dispatched, with bulletin text and audio link |

Joins: `hydro_observations.station_id` → `stations.id`; `sentinel_alerts.commune_id` → `communes.code`; `weather_forecasts.province_code` → `communes.province_code`. `source` = `live` (MRC API) or fallback (stale/failover offset applied) in hydro observations.

## commune / commune properties

| Field | Meaning |
| --- | --- |
| `code` | 6-digit commune PCODE without the `KH` prefix (join key; `KH` + code = `ADM3_PCODE` in OCHA shapefiles) |
| `name_en`, `name_kh` | Commune name, English and Khmer script |
| `district_code`, `province_code` | 4-digit and 2-digit parent PCODEs (same prefix rule) |
| `district_*`, `province_*` | Parent names, EN/KH |
| `lat`, `lng` | Representative point (WGS 84); centroid of the boundary where available |
| `has_boundary` | Whether a polygon exists in the source |
| `ground_elevation_m` | Meters above sea level, Copernicus DEM GLO-90 sampled at the representative point |
| `nearest_station_id` | Nearest MRC station (join to `stations.csv`) |
| `distance_to_station_km` | Great-circle distance to that station |

## stations

| Field | Meaning |
| --- | --- |
| `id` | MRC station code (join key for `nearest_station_id`) |
| `river` | Mekong or Tonle Sap / Bassac |
| `alarm_stage_m`, `flood_stage_m` | MRC alert thresholds, meters above local zero gauge |
| `zero_gauge_elevation_m` | Local gauge datum vs sea level (null where unpublished; needed to compare stage against `ground_elevation_m`) |
| `fallback_id` | Adjacent station used when this one is offline |

## Provenance

- Names/lists: Cambodia Commune/District/Province List 2025, MEF DataEF portal (data.mef.gov.kh), accessed Oct 2026.
- Boundaries: MLMUPC Dept. of Geography commune boundaries (OCHA lineage, `validOn` 2018-10-04), via MEF DataEF.
- Elevation: Open-Meteo Elevation API (Copernicus DEM GLO-90).
- Station metadata: live MRC telemetry API (api.mrcmekong.org), verified 2026-10-17; alarm/flood stages from the MRC Flood Forecasting bulletin (ffw.mrcmekong.org).
- timeseries/: recorded from the upstream MRC and Open-Meteo APIs by the staging deployment's patrol cron; exported 2026-10-25 from its PostgreSQL (`mekongpulse` db on labyrinth.ts).
- historical/: scraped from the MRC RFMMC public hydrograph backend (ffw.mrcmekong.org) on 2026-10-25; the same numbers that power the station pages on that site.

For fresh data at runtime use the MRC telemetry API (`api.mrcmekong.org/api/v1`) and Open-Meteo (`api.open-meteo.com/v1/forecast`, province-point queries); see `projects/shared/src/mekong_shared/mrc.py` and `weather.py` for reference implementations.

## Quick start

```python
import pandas as pd
import geopandas as gpd

communes = pd.read_csv("communes.csv", dtype={"code": str, "district_code": str, "province_code": str, "nearest_station_id": str})
stations = pd.read_csv("stations.csv", dtype={"id": str, "fallback_id": str})
hydro = pd.read_csv("timeseries/hydro_observations.csv", parse_dates=["recorded_at", "fetched_at"])
hist = pd.read_csv("historical/mrc_daily_all.csv", parse_dates=["date"])
gdf = gpd.read_file("communes.geojson")

df = communes.merge(stations, left_on="nearest_station_id", right_on="id", how="left")
```
